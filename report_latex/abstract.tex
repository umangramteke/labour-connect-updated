\markboth{Abstract}{Abstract}

The unorganized blue-collar labor market in developing nations such as India faces severe challenges of informal employment insecurity, wage ambiguity, and absence of standardized verification mechanisms for hyperlocal trade contractors (such as masons, carpenters, plumbers, and electricians). Simultaneously, commercial and residential employers experience significant friction in identifying certified, background-verified personnel with transparent pricing. This project presents \textbf{Labour Connect}, a full-stack digital web platform developed utilizing the modern \textbf{MERN stack} (MongoDB Atlas, Express.js, React.js, and Node.js) to bridge these structural divides.

The system incorporates two unified operational verticals: an \textit{Employment Connect} marketplace catering to daily-wage and regular monthly job listings with candidate wage bidding, and an \textit{On-Demand Service Connect} engine managing real-time household maintenance bookings through a validated five-step lifecycle state machine (\texttt{REQUESTED} $\rightarrow$ \texttt{ACCEPTED} $\rightarrow$ \texttt{ON\_THE\_WAY} $\rightarrow$ \texttt{SERVICE\_STARTED} $\rightarrow$ \texttt{COMPLETED}). The platform enforces strict Role-Based Access Control (RBAC) across five specialized user categories (\texttt{ROLE\_ADMIN}, \texttt{ROLE\_EMPLOYER}, \texttt{ROLE\_WORKER}, \texttt{ROLE\_CUSTOMER}, and \texttt{ROLE\_PROVIDER}) secured via stateless JSON Web Tokens (JWT) and Bcrypt cryptographic password hashing. An atomic sequence counter system is engineered within MongoDB to ensure numeric identifier integrity, and the Haversine trigonometric formula is integrated for proximity-based provider discovery.

Comprehensive automated verification demonstrates a 100\% pass rate across 16 end-to-end integration test suites executing in 2.6 seconds, alongside an optimized frontend build of 1,672 modules compiling with zero defects in 3.56 seconds. The entire architecture has been deployed live to the cloud, utilizing Vercel Global Edge CDN for the client tier, Render Cloud Web Services for the Node.js REST API gateway, and MongoDB Atlas AWS Mumbai for high-availability database clustering.

\vspace{5mm}
\noindent\textbf{Keywords:} MERN Stack, MongoDB, Express.js, React.js, Node.js, Blue-Collar Employment, Hyperlocal Services, RESTful API, Role-Based Access Control, Cloud Deployment.
